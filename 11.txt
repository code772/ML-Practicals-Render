#Practical 11: Reinforcement Learning Using Q-Learning

import numpy as np
import random
import matplotlib.pyplot as plt

Q = np.zeros((16, 4))

alpha = 0.1
gamma = 0.9
epsilon = 1.0
rewards = []

for episode in range(1000):
    state = 0
    total_reward = 0

    for step in range(50):

        if random.random() < epsilon:
            action = random.randint(0, 3)
        else:
            action = np.argmax(Q[state])

        if action == 0:
            new_state = max(0, state - 4)
        elif action == 1:
            new_state = min(15, state + 4)
        elif action == 2:
            new_state = state if state % 4 == 0 else state - 1
        else:
            new_state = state if state % 4 == 3 else state + 1

        reward = 10 if new_state == 15 else -1

        Q[state, action] += alpha * (
            reward + gamma * np.max(Q[new_state]) - Q[state, action]
        )

        state = new_state
        total_reward += reward

        if state == 15:
            break

    rewards.append(total_reward)
    epsilon = max(0.01, epsilon * 0.995)

print("Training Completed")
print("Average Reward:", np.mean(rewards[-100:]))

# Optimal Policy
arrows = ["↑", "↓", "←", "→"]

print("\nOptimal Policy:")

for i in range(16):
    if i == 0:
        print("S", end="  ")
    elif i == 15:
        print("G", end="  ")
    else:
        print(arrows[np.argmax(Q[i])], end="  ")

    if (i + 1) % 4 == 0:
        print()

# Performance Graph
plt.plot(rewards)
plt.xlabel("Episodes")
plt.ylabel("Reward")
plt.title("Q-Learning Performance")
plt.show()

1. Important definitions
1. Reinforcement Learning (RL): A type of machine learning in which an agent learns by interacting with an environment and receiving rewards or penalties for its actions.

2. Agent: The learner or decision-maker that performs actions. In your practical, the agent is the player moving through the grid.

3. Environment: The world in which the agent operates. In your practical, it is the 4×4 grid.

4. State: The current position or situation of the agent. Your grid has 16 states, numbered 0 to 15.

5. Action: A move performed by the agent. Your practical has four actions: Up, Down, Left and Right.

6. Reward: Feedback received after performing an action. In your code, reaching the goal gives +10, while every other move gives -1.

7. Q-Value: A numerical value that represents how good a particular action is in a particular state.

8. Q-Table: A table that stores Q-values for every state-action pair. Your code uses a 16×4 Q-table.

9. Q-Learning: A model-free, off-policy reinforcement learning algorithm that learns the best action to take in each state by updating Q-values.

10. Learning Rate (α): Determines how much new information is used to update the Q-value. Your value is 0.1.

11. Discount Factor (γ): Determines the importance of future rewards compared to immediate rewards. Your value is 0.9.

12. Exploration: Trying random actions to discover better paths or rewards.

13. Exploitation: Choosing the action with the highest known Q-value.

14. Epsilon (ε): Controls the probability of exploration. Your code starts with ε = 1.0 and gradually decreases it.

15. Optimal Policy: The best strategy that tells the agent which action to take in each state to maximize its total expected reward.

16. Episode: One complete training attempt, starting from the initial state and ending when the goal is reached or the step limit is reached.

17. Terminal State: The final state where the episode ends. In your practical, state 15 is the goal.
2. Important formulas
1. Q-Learning Update Formula
Most important formula
\[
Q(s,a) \leftarrow Q(s,a)+\alpha
\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right]
\]

Where:
- \(Q(s,a)\) = Current Q-value
- \(\alpha\) = Learning rate (0.1)
- \(r\) = Immediate reward
- \(\gamma\) = Discount factor (0.9)
- \(s'\) = Next state
- \(\max Q(s',a')\) = Maximum future Q-value
Meaning: It updates the current Q-value using the reward received and the best possible future reward.
2. Epsilon-Greedy Action Selection
\[
a =
\begin{cases}
\text{Random action}, & \text{if } random < \epsilon\\
\arg\max_a Q(s,a), & \text{otherwise}
\end{cases}
\]

Meaning: The agent sometimes explores by choosing a random action and otherwise exploits its learned knowledge.
3. Epsilon Decay Formula
\[
\epsilon_{\text{new}}=\max(0.01,\epsilon_{\text{old}}\times0.995)
\]

Meaning: Epsilon decreases gradually, reducing random actions as training progresses. It never goes below 0.01.
4. Total Episode Reward
\[
R_{\text{total}}=\sum_{t=1}^{T}r_t
\]

Meaning: It is the sum of all rewards received during one episode.
5. Average Reward
\[
\text{Average Reward}=
\frac{\text{Sum of rewards}}{\text{Number of episodes}}
\]

In your code, the average is calculated for the last 100 episodes:
\[
\text{Average Reward}=
\frac{\sum_{i=901}^{1000}R_i}{100}
\]

6. Optimal Action Selection
\[
\pi(s)=\arg\max_a Q(s,a)
\]

Meaning: The agent selects the action having the highest Q-value in the current state. This gives the learned policy.
