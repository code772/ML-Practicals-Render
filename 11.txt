#Practical 11: Reinforcement Learning Using Q-Learning

import numpy as np
import random
import matplotlib.pyplot as plt

Q = np.zeros((16, 4))

alpha = 0.1
gamma = 0.9
epsilon = 1.0
rewards = []

for episode in range(1000):
    state = 0
    total_reward = 0

    for step in range(50):

        if random.random() < epsilon:
            action = random.randint(0, 3)
        else:
            action = np.argmax(Q[state])

        if action == 0:
            new_state = max(0, state - 4)
        elif action == 1:
            new_state = min(15, state + 4)
        elif action == 2:
            new_state = state if state % 4 == 0 else state - 1
        else:
            new_state = state if state % 4 == 3 else state + 1

        reward = 10 if new_state == 15 else -1

        Q[state, action] += alpha * (
            reward + gamma * np.max(Q[new_state]) - Q[state, action]
        )

        state = new_state
        total_reward += reward

        if state == 15:
            break

    rewards.append(total_reward)
    epsilon = max(0.01, epsilon * 0.995)

print("Training Completed")
print("Average Reward:", np.mean(rewards[-100:]))

# Optimal Policy
arrows = ["↑", "↓", "←", "→"]

print("\nOptimal Policy:")

for i in range(16):
    if i == 0:
        print("S", end="  ")
    elif i == 15:
        print("G", end="  ")
    else:
        print(arrows[np.argmax(Q[i])], end="  ")

    if (i + 1) % 4 == 0:
        print()

# Performance Graph
plt.plot(rewards)
plt.xlabel("Episodes")
plt.ylabel("Reward")
plt.title("Q-Learning Performance")
plt.show()

## 2. Theory

### What is Reinforcement Learning?

**Definition:** Reinforcement Learning (RL) is a type of Machine Learning in which an agent learns by interacting with an environment and receiving rewards or penalties for its actions.

In simple words, an agent tries different actions, receives rewards or penalties, and learns which actions are better.

**Example:**

Imagine teaching a child to reach a destination.

- If the child moves towards the destination, a reward is given.
- If the child takes unnecessary steps, a penalty is given.
- After repeated attempts, the child learns the correct path.

This is the basic idea of Reinforcement Learning.

### Components of Reinforcement Learning

| Component | Meaning |
|---|---|

| Environment | The place where the agent operates. |
| State | The current position of the agent. |

4. Agent receives a reward or penalty.
5. Agent updates its knowledge.

## 6. Q-Learning Mathematical Formula

The Q-Learning algorithm uses the following formula to update Q-values:

```text
Q(s,a) = Q(s,a) + Alpha × [Reward + Gamma × Max Q(s',a') - Q(s,a)]
```

### Explanation of Symbols

| Symbol | Meaning |
|---|---|
| Q(s,a) | Current Q-value |
| Alpha | Learning rate |
| Reward | Immediate reward |
| Gamma | Discount factor |
| s | Current state |
| a | Current action |
| s' | New state |
| Max Q(s',a') | Maximum future Q-value |

### Working of the Formula

1. Get the current Q-value.
2. Receive the immediate reward.
3. Find the maximum Q-value of the new state.
4. Multiply the future Q-value by Gamma.
5. Calculate the difference between the target and old Q-value.
6. Multiply the difference by Alpha.
7. Add the result to the old Q-value.

### Numerical Example

Suppose:

- Old Q-value = 2
- Reward = 10
- Alpha = 0.1
- Gamma = 0.9
- Maximum Future Q-value = 8

Formula:

```text
Q(New) = Q(Old) + Alpha × [Reward + Gamma × Max Q - Q(Old)]
```

Substituting the values:

```text
Q(New) = 2 + 0.1 × [10 + (0.9 × 8) - 2]

Q(New) = 2 + 0.1 × [10 + 7.2 - 2]

Q(New) = 2 + 0.1 × 15.2

Q(New) = 2 + 1.52

Q(New) = 3.52
```

Therefore, the updated Q-value is **3.52**.

import numpy as np
import random
import matplotlib.pyplot as plt

Q = np.zeros((16, 4))

alpha = 0.1
gamma = 0.9
epsilon = 1.0
rewards = []

for episode in range(1000):

    rewards.append(total_reward)

print("Training Completed")

- `np.max(Q[new_state])`: Finds the maximum future Q-value.
- `gamma`: Applies the discount factor.
- `alpha`: Controls the learning rate.

The Q-value is updated using the new information.

### I. Moving to the New State

```python
state = new_state
total_reward += reward
```

- Updates the current state.
- Adds the reward to the total reward.

### J. Checking the Goal

```python
if state == 15:
    break
```

Checks whether the agent has reached the goal.

If the agent reaches state 15, the current episode terminates.

### K. Storing Rewards

```python
rewards.append(total_reward)
```

Stores the total reward of each episode in the rewards list.

### L. Reducing Epsilon

```python
epsilon = max(0.01, epsilon * 0.995)
```

Gradually reduces the exploration rate after every episode.

This process is called **Epsilon Decay**.

It helps the agent move from exploration towards exploitation.

### M. Displaying Training Results

```python
print("Training Completed")
print("Average Reward:", np.mean(rewards[-100:]))
```

- Displays the training completion message.
- Calculates the average reward of the last 100 episodes.

Formula:

```text
Average Reward = Sum of Rewards / Number of Episodes
```

arrows = ["↑", "↓", "←", "→"]
