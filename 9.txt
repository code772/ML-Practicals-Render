# Practical 9: DBSCAN Clustering
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import DBSCAN
from sklearn.preprocessing import StandardScaler

df = pd.read_csv(r"make_moons.csv")

X = df[["Feature_1", "Feature_2"]]
X = StandardScaler().fit_transform(X)

model = DBSCAN(eps=0.5, min_samples=5)
df["Cluster"] = model.fit_predict(X)

print(df)

clusters = df["Cluster"].nunique()
if -1 in df["Cluster"].values:
    clusters -= 1

print("Number of Clusters:", clusters)
print("Noise Points:", list(df["Cluster"]).count(-1))

plt.scatter(X[:, 0], X[:, 1], c=df["Cluster"], cmap="rainbow")
plt.xlabel("Feature 1")
plt.ylabel("Feature 2")
plt.title("DBSCAN Clustering")
plt.show()

Practical 9: DBSCAN Clustering
1. Aim
To employ a density-based clustering algorithm such as DBSCAN on a suitable open-access dataset to identify the clustering structure and noise points.
2. What is DBSCAN?
DBSCAN stands for Density-Based Spatial Clustering of Applications with Noise.

It is an unsupervised machine learning algorithm that groups closely packed data points into clusters and identifies isolated points as noise or outliers.

Example: Grouping customers based on similar purchasing patterns and identifying unusual customers.
3. What is Density-Based Clustering?
Density-based clustering groups data points according to how closely they are located to one another.
- High-density regions form clusters.
- Low-density regions are treated as noise.
- Clusters can have irregular shapes.
4. Important Parameters of DBSCAN
DBSCAN mainly uses two parameters:

1. Epsilon (eps)

It specifies the maximum distance between two points for them to be considered neighbours.
- Small eps → More points may be classified as noise.
- Large eps → More points may be included in clusters.
2. Min_samples

It specifies the minimum number of neighbouring points required to form a dense region.
- High Min_samples → More points are likely to be classified as noise.
- Low Min_samples → Clusters can form with fewer points.
5. Types of Points in DBSCAN
DBSCAN classifies data points into three types:

1. Core Point
- A point having at least Min_samples points within its eps neighbourhood.
- It lies in a dense region.
2. Border Point
- A point that has fewer than Min_samples neighbours within its own eps neighbourhood.
- It lies within the eps neighbourhood of a core point.
3. Noise Point
- A point that is neither a core point nor a border point.
- It does not belong to any cluster.
6. How DBSCAN Works
1. Load a suitable dataset.
2. Select the required numerical features.
3. Standardize the features.
4. Set the eps and Min_samples parameters.
5. Calculate the neighbourhood of each data point.
6. Identify core points.
7. Form clusters by connecting density-reachable points.
8. Mark points that do not belong to any cluster as noise.
9. Visualize the clusters and noise points.

8. How to Identify Noise Points?
DBSCAN assigns the label -1 to noise points.
